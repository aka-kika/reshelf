# reshelf update feed

This branch exists only to serve the Sparkle appcast for
[reshelf](https://github.com/aka-kika/reshelf) at
<https://aka-kika.github.io/reshelf/appcast.xml>.

`appcast.xml` is generated by `scripts/appcast.sh` on `main` and signed with the
publisher's EdDSA key. Application binaries live on the GitHub Releases page, not
here. Nothing on this branch is hand-edited.
