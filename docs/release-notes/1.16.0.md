Notarized Developer ID build for macOS 14 or newer. Open the DMG and drag reshelf to Applications (replace the old one).

New in 1.16.0
- **Restore can undo a change:** in Restore from Backup, turn on "Also put back changes to repos I still have" and repos that changed since the backup get their shelf, tags, notes and folder back. The sheet counts them first.
- **Backups say what they were for:** the backup taken before a big change is labelled, like "Before moving 12 repos to Yard Sale", so the right one is easy to pick.
- **What's new:** this sheet, once after each update, and again from Help.

Fixes in 1.16.0 (from the 20 October code review)
- **No crash when you delete a repo** while reshelf is still working on it (Capture Assist, Refresh Info, Pull, Check Clones).
- **Refresh Info asks first** before it moves repos GitHub can't find to Yard Sale, and names them. Private repos your token can't see also come back as "not found".
- **Remove Duplicate Repos keeps everything you wrote** on either copy: tags, use cases and both notes.
- **Pull keeps your own commits,** even ones you also tagged.
- **You can empty your shelf:** deleting every repo no longer brings them back at the next launch.
- **A failed save says so** instead of looking fine and losing the change.
- **Check Clones says when it couldn't check** (offline, or git missing) instead of "All clones are up to date". The inspector now follows its result.
- **SSH links work:** a link pasted as git@github.com:owner/repo is saved as a normal link, and ones saved broken before are fixed at launch.
- **git never hangs:** a private repo fails at once with a plain message, and a stuck check or pull stops and moves on to the next clone.
- **Your own projects stay yours:** with a custom clone folder, only folders in reshelf's own layout count as clones, and a clone cut off midway is no longer shown as Cloned.
- **Import GitHub URLs can be stopped,** and stops at GitHub's limit keeping the rest of your links for later.
- **More licenses explained:** EUPL, PostgreSQL, CC-BY and WTFPL, and a plain note for any license reshelf doesn't know.
- **Smaller fixes:** honest text in the recovery alert; no crash loop if the catalog file can't be opened; Settings tells you when the token couldn't be saved; no two repos share one id after a restore; a clear message when git's Command Line Tools are missing; a note about clones left in the old folder when you change the clone folder; faster backups and Restore list.
