Notarized Developer ID build for macOS 14 or newer. Open the DMG and drag reshelf to Applications (replace the old one).

Fixes in 1.16.1 (from the 24 and 25 October code reviews)
- **Your clones in a custom clone folder keep their Cloned badge.** The first time 1.16.1 starts, clones an older version made there are recognized again, but only where reshelf would have put them for a repo in your catalog. Choosing the default folder by hand counts as the default.
- **A clone on another branch is checked against that branch,** and Pull keeps it on that branch instead of switching to the default one. A tag you moved onto your own commit is no longer overwritten when Pull stops.
- **Refresh Info keeps a license you typed** when GitHub says there is none.
- **A failed save is honest everywhere:** Import GitHub URLs stops and keeps the links, Import Catalog and Restore say nothing changed, and Cancel in Edit leaves the repo as it was. The alert shows on the window, so it can't freeze behind a sheet.
- **Backups stay tidy:** the newest 40 "Before ..." backups are kept beside the 30 routine ones, and many backups in one second are kept in the right order.
- **Quick Capture:** fetching a second link clears the first repo's "Why you're saving this", and keeps anything you typed while it fetched.
- **⌘T, ⌘Y and ⌘⇧G with a batch** move only the rows you can see, then clear the batch.
- **Clone recovers from a clone cut off before any download,** and never replaces a repo folder you made yourself.
- **Faster and calmer:** coming back to reshelf rescans the clone folder in the background, icons are sized to fit and drawn safely, and an avatar that failed is not asked for again for a day.
- **Many smaller fixes:** search finds a repo by its owner or website, a repo named tree or blob can be captured, a custom category is no longer filed under a shorter one, a blank folder rename is simply ignored, Move N Clones to Trash lists every failure, and more.
