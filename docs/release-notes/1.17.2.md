Notarized Developer ID build for macOS 14 or newer. Open the DMG and drag reshelf to Applications (replace the old one).

New in 1.17.2
- **Agents clear the fits they checked.** After reading one of your repos' fits, your agent hides the ones that do not fit and marks the ones it borrowed from, so the next session does not read the same list again. reshelf hides them in your list the next time it comes to the front, after a backup. Show Hidden Fits brings any of them back. Install the skill again from Settings → Library → Agent Skill to get it.

Also in 1.17
- **The agent skill speaks about you.** Repos with the UI mark show "UI: you like its UI" to your agent.
- **Hide what does not fit.** Right-click a fit and choose Hide from its list. Show Hidden Fits brings it back.
- **Reshelfed.** When an agent borrows code from a shelf repo for one of your projects, it thanks the author in that project's ACKNOWLEDGEMENTS.md and reshelf shows "Reshelfed in <project>".
