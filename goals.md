# Goals

Why **reshelf** exists, and the principles that guide it.

## Primary goal

A **personal, local-first shelf** for open-source repos — not a generic bookmark
list. You collect repos worth *your* time, decide where they sit, and pull the
source close when you want to learn from or use it. Everything stays on your Mac.

## User outcomes

1. **Capture fast** — a GitHub link becomes a categorized entry in seconds.
2. **Decide clearly** — shelves (Top Shelf / The Collector / Yard Sale) and a fit
   score capture "keep, maybe, or let go" without ceremony.
3. **Find by intent** — filter by shelf, by auto-classified category, or by what
   you've actually cloned.
4. **Bring the code close** — clone repos locally, grouped by category, and know
   when a clone has updates to pull.
5. **Stay private** — no account, no cloud; your catalog and clones are yours.
6. **Grow into analysis** — an optional intelligence layer (clones + AI) can add
   deeper context later, without complicating the simple shelf.

## Product principles

- **Local-first & private** — no sign-in, no required cloud, credentials in Keychain.
- **Zero-setup core** — the catalog works offline with no configuration; anything
  that needs git, AI, or keys is opt-in.
- **Mac-native polish** — unified window chrome, split view, real keyboard shortcuts.
- **Calm by default** — a stable list/detail with good empty states; power features
  stay out of the way until you reach for them.
- **Honest scope** — reshelf *evaluates and remembers* tools and brings their source
  close. It is not a package manager or a full GitHub client.
- **Hard to lose data** — isolated store, automatic backups, restore paths.
- **Plain-language help** — explain the tricky stuff (like software licenses) in
  terms anyone can act on.

## Success signals (informal)

- New repos land via **⌘K / ⌘⇧N**, not lost browser tabs.
- Your **Top Shelf** stays short and trustworthy; the rest is easy to triage.
- Notes + category are enough to reopen a project months later.
- When you want to build something, your **cloned shelf** is the first place you look.

## Non-goals (for now)

- Team libraries or cloud sync
- Required login or third-party analytics
- A full GitHub client or a package manager
- Replacing Obsidian / Notion / your PKM
- Fourth-column inspectors or disconnected floating panels
