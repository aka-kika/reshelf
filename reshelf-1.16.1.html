Fixes from the 24 October review (Grok's pass), its second check, and the seven leftovers on the Runway card.

Fixed

  • Clones in a custom clone folder made before 1.16.1 keep their Cloned badge. On the first launch, a clone at the exact folder reshelf would have used for a catalog repo, with that repo as its origin, gets the marker. Clone no longer makes a second copy of it, and Remove Local Clone reaches it. A clone folder set to the default path by hand counts as the default.
  • Update checks and Pull follow the checked-out branch. A clone on another branch that upstream has is compared with that branch and stays on it after Pull. Tags are fetched only after the safety checks, and a tag moved onto a local commit still protects it.
  • Labelled "Before …" backups stop at the newest 40, told apart by file name, so pruning no longer opens every backup. A labelled backup from 1.16.0 is renamed, not deleted, when it ages out.
  • Backups written in the same second keep their order. A new one is numbered above the others instead of into a gap a prune left, where it sorted as older and was pruned at once.
  • A timed-out git command no longer closes pipes another thread is reading. The 1.16.0-review change that did is reverted; the readers finish on their own.
  • Import GitHub URLs, Import Catalog and Restore use the save result. A repo that could not be saved is not counted, the run stops and keeps the links, and the unsaved rows are taken back out. Edit puts the repo back as it was on a failed save, so Cancel keeps nothing.
  • The save-failed alert is a sheet on the front window, not a modal run from async code that could freeze with a sheet open.
  • Refresh Info keeps a hand-typed license when GitHub reports none or NOASSERTION. A real license from GitHub still replaces it.
  • Coming back to reshelf rescans the clone folder off the main thread. A scan that started before a clone or a removal does not overwrite the newer index.
  • Icons fit inside 64 pt (wide ones were larger) and are resized with ImageIO, safe off the main thread.
  • An avatar that failed is not asked for again for a day, one entry per owner, so a relaunch or a bulk import does not ask once per repo.
  • Quick Capture's second fetch clears the first repo's "Why you're saving this" too, and keeps anything typed while the fetch ran.
  • ⌘T, ⌘Y and ⌘⇧G move only the batch rows the list shows, clear the batch afterwards, and a batch of one moves that row.
  • A clone cut off before any data arrived is replaced by the next Clone. A hidden file beside the target marks a clone reshelf started; a checkout someone made with no commits is still left alone.
  • A blank folder rename is ignored instead of saying the name is already used.
  • The agent skill reads a clone's identity from the origin remote only, like the app.
  • features.md says where a category outside the sidebar set shows (All Projects and search).
  • The restore preview reads the backup file off the main thread. Choosing a backup no longer decodes it on the thread that draws the window.
  • Clone no longer replaces a checkout that has no commits yet. Only a clone that never wrote its index is moved to the Trash. Anything else is left in place and reported as in the way.
  • The metadata lookup no longer has a dead second URL check. It matches the GitHub link, then owner and name. The docs say the same.
  • Edit refuses a name that is only spaces. Save stays off, so a row cannot become blank.
  • A repo named like a compound topic is categorized from that name. browser-use lands in Computer Use even when GitHub sent no topics.
  • Renaming a folder onto an existing name is refused. Capitals do not make it a different folder, same as creating one.
  • Move N Clones to Trash lists every failure. An earlier clone that could not be moved is no longer replaced by the last message.
  • Send to reshelf stops when the save fails. It no longer fetches an icon or runs Capture Assist for a repo that was not saved. Quick Capture already stopped.
  • A failed Send to reshelf link says why. The list status line shows the reason instead of only beeping.
  • Why I saved this reports a failed save. Leaving the field saves through the same path as the rest of the catalog, so a full disk shows the alert.
  • A failed save no longer finishes the one-time category merge. Clone folders stay put, and the merge runs again next launch.
  • Remove Duplicate Repos keeps Local-First and Self-Hosted. A flag set on either copy stays set, and it counts when choosing which copy to keep.
  • Emptying the shelf is remembered immediately. A quit in that moment no longer lets the next launch restore every repo.
  • Picking a repo in Search shows it, even when a filter was hiding it. The list goes back to All Projects and the search box clears.
  • The inspector no longer shows another owner's description when this repo has no metadata row yet. The lookup matches owner and name, not the bare repo name.
  • Two quick Send to reshelf links for the same repo save it once. The duplicate check runs again after the GitHub fetch.
  • Fetching a second link in Quick Capture clears the first repo's note, use cases and flags.
  • Return while Quick Capture is still fetching does not start a second request.
  • A catalog restored at launch is classified. The one-time category tidy no longer marks itself done while it is still looking at the empty list from before the restore.
  • Import GitHub URLs writes a labelled backup before it adds anything. If that backup cannot be written, nothing is imported and the links stay in the box.
  • The agent skill's folder map cannot be pointed outside the clone folder. A category name is cleaned the same way the app cleans one, so "." and ".." and slashes stay inside the clone root.
  • Refresh Info no longer says every repo is cloned when some have no GitHub link. It says so.
  • A clone is recognized from its origin remote only. Another github.com link in the git config no longer decides which repo the folder is.
  • Saving a repo and deleting it in the same moment no longer crashes. The metadata step checks the row is still there before it reads it.
  • C, C++ and C# stay three tags. The sidebar no longer folds + and # out of a tag.
  • Search finds a repo by its owner or its website. Both links are part of the search.
  • A custom category is no longer filed under a shorter one. Client does not show under CLI, and Multimedia does not show under Media. The sidebar matches the whole category name.
  • A repo or an owner named tree or blob can be captured. Those words are only skipped when they come after the repo, as in a link to a file or a branch.
  • A backup taken before you had any folders can take a repo back out of a folder. The file now records an empty folder list instead of leaving the list out.
  • GitHub's second rate limit stops Refresh. A 403 that carries Retry-After is treated as the limit, so Refresh does not keep asking.
  • Quick Capture does not fetch a README. The docs no longer say it can.
  • A few doc lines now match the app. ⌘K does not keep recent searches. The agent skill installs from Settings → Library, and it is the only skill in extras. The GitHub token is already in Settings → Capture. An emptied shelf is not refilled from a backup.
  • Restore no longer brings back a folder you deleted when it has nothing to restore. A folder is created only when a repo coming back from that backup uses it.
  • Clone no longer deletes a file that is sitting where the clone would go. An empty leftover folder goes to the Trash. Anything else stops the clone and stays put.
  • Quick Capture has a Notes field. The note Capture Assist writes is on the form before you save.
  • ⌘-click adds to the row you already clicked. The batch count matches the rows that look selected, and ⌘T, ⌘Y and ⌘⇧G move that batch.
  • Put back changes restores the shelf, tags, notes and folder only. Name, links, description and category stay as they are. The restore sheet already said this.
  • A backup taken before a big change is not deleted when the 30 routine snapshots fill up. Restore from Backup can still find that undo point.
  • Import GitHub URLs keeps a link that failed. Offline, or with a bad token, the links that didn't import stay in the box for the next try. Duplicates that were skipped do not.
  • The one-time category merge no longer moves folders inside a custom clone folder. That folder can hold your own projects, and the merge does not check that a folder is a clone.
  • Moving a batch of repos to a shelf, and deleting a folder, write a labelled backup first. If that backup cannot be written, nothing changes. Restore from Backup can undo either one.
  • A backup that cannot be written no longer says it was saved. Delete, Remove Duplicate Repos and the Yard Sale moves stop, and say to check the disk has free space.
  • The Website link opens only web pages. A homepage set to `file://` or `smb://` is no longer handed to Finder.
  • Shelf moves, tags, notes and folder changes are backed up within 2 seconds, the same as adding or deleting a repo. Before, those waited until you quit.
  • Deleting a repo while it is cloning no longer crashes. The status line keeps the repo's name from before the clone started.
  • A custom clone folder no longer treats your own projects as clones. Remove Local Clone and Pull only touch clones reshelf made (a marker written when the clone finishes). Clones already in the default folder are marked the first time they're seen. A checkout in a folder you chose is left alone, and the agent skill follows the same rule.

Cleanup (2026-10-20, no change in what the app does)

  • Removed dead code left from the old intelligence engine: the unused status
    • pipeline (`CatalogIntelligenceStatus` and the resolver's snapshot path), the AI insight and score record types, unused database, git, folder, bridge and updater helpers, and the unused `extras/afm-harness` script. Database tables stay, so the store does not change.
  • Clones: the never-used partial-clone (`blobless`) option is gone; clones are
    • the same full clones as before.
  • Fixed outdated code comments and three stale doc lines.
